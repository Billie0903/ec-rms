# EC-RMS: Elderly Center Resident Management System

A web app for an elderly care center to manage residents' care records, with a private, read-only view for each resident's family.

Stack: React (Vite) · Node.js (Express) · MySQL.

> Work in progress. Installation, `.env` setup and run instructions will be added as the code lands. See [`docs/`](docs/) for the spec and database design.
